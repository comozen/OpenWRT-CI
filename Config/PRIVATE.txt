# 私有覆盖配置 · Config/PRIVATE.txt
# ==============================================================================
#
# 加载顺序（见 .github/workflows/WRT-CORE.yml 的 Custom Settings 步骤）：
#
#   Config/IPQ95XX.txt  ->  Config/GENERAL.txt  ->  Scripts/Settings.sh
#   ->  Config/PRIVATE.txt（本文件）  ->  Run workflow 的 PACKAGE 输入框
#   ->  make defconfig
#
# .config 后写入的项覆盖先写入的，所以本文件优先级高于 GENERAL.txt、
# 低于 PACKAGE 输入框。想单独改某一项又不想动 GENERAL.txt（避免与上游
# VIKINGYFY/OpenWRT-CI 同步时产生冲突），就把覆盖行写在这里。
#
# 内容限制：只允许以 # 开头的注释、以 CONFIG_ 开头的配置行和空行。
# 其它文本会污染 .config。
#
# 生效前提：目标包必须已存在于源码树或 feed 中。若不存在，先在
# Scripts/Packages.sh 增加一条 UPDATE_PACKAGE 拉取源码，否则这里写
# =y 会被 make defconfig 静默丢弃、且不报错。
#
# 设备与平台选择不要写在本文件，放 Config/IPQ95XX.txt。
#
# 验证方式：用 QCB-ALL 勾选 TEST 跑一轮（约 10 分钟，不编固件但照样
# 执行 make defconfig），从生成的 Release 里下载 Config-*.txt，
# 确认覆盖行按预期生效。
# ==============================================================================
